# Piring Calorie Tracker

A phone app for logging food, drinks, workouts and weight, with daily nutrition recommendations.

Open https://alifsutowo74.github.io/piring/ in Chrome on your phone and tap **Install app** (or menu → Add to Home screen).
Your log is stored on your device. Use **Target → Backup** to save or restore it.

## Changing the app
Edit `src/artifact.html`, then run `python3 src/build.py` from the repo root to regenerate `index.html`, `manifest.webmanifest` and `sw.js`.
